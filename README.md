# Note Pad with Password (Vault) 🔐

A modern, highly secure Native Android Notepad App built with **Kotlin** and **Jetpack Compose**, featuring password protection and AES-256 encryption.

---

## 🌟 Key Features
- **Master Password Protection**: Protects your confidential notes behind SHA-256 salted hash authentication.
- **AES-256 GCM Storage**: Notes are encrypted at rest using Android Jetpack Security (`EncryptedSharedPreferences`).
- **Modern Jetpack Compose UI**: Fast, responsive, dark-mode focused experience.
- **Real-time Search**: Instant keyword filtering across titles and notes.
- **Quick Lock & Password Management**: One-tap vault lock and password rotation.
- **Automated Cloud Builds**: Built via GitHub Actions with signed production APK ready to download.
